INCY details

INCY uses incy://crypt1/… with AES-256-GCM and a public shared key. This conceals the URL in messages; anyone with the encoder can recover it. Use an updated INCY app.

To disable normal URL sharing and backups in INCY, your subscription server must also return hide-url: 1. This page cannot set that response header.
